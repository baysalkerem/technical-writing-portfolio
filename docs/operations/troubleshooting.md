# Troubleshoot common issues

Use these checks to narrow down common problems before escalating to a platform administrator.

| Symptom | First check | Next action |
| --- | --- | --- |
| Agent cannot sign in | Account activation and assigned role | Review identity provider sign-in logs |
| Agent receives no offers | Availability and queue membership | Inspect queue routing events |
| CRM data does not appear | Integration connection status | Verify field mapping and permissions |
| Interactions disconnect | Network connectivity and service health | Correlate session events with service alerts |

## Collect diagnostic details

1. Record the time of the issue, including the time zone.
2. Record the affected user role, queue, and interaction channel.
3. Capture the error message and relevant correlation identifier.
4. Remove sensitive customer information from the diagnostic package.
5. Share the package through the approved support channel.

:::note
Avoid changing multiple configuration settings at once. Reproduce the issue after each approved change.
:::
