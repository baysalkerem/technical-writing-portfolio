# Handle a customer interaction

Accept an incoming interaction, review the customer context, and record the outcome.

## Prerequisites

- Set your status to **Available**.
- Connect your audio device if you expect voice interactions.

## Accept an interaction

1. In the incoming interaction notification, review the channel and queue name.
2. Select **Accept**. The interaction opens in the interaction panel.
3. Review the customer details and available interaction history.
4. Respond to the customer using the controls for the active channel.

## Complete the interaction

1. Select **End interaction** when the conversation finishes.
2. In the wrap-up panel, select an outcome code.
3. Enter a concise summary of the resolution.
4. Select **Save and close**. The interaction appears in your activity history.

:::caution
Do not enter passwords, payment card details, or other sensitive information in free-text notes.
:::
