# Create an agent account

Create an agent account and assign the permissions needed to handle customer interactions.

## Prerequisites

- Sign in to the administration console with the **User administrator** role.
- Obtain the agent's name, work email address, and queue assignment.

## Create the account

1. In the administration console, go to **Identity > Users**.
2. Select **Create user**.
3. Enter the agent's name and work email address.
4. In **Role**, select **Agent**.
5. In **Queue assignments**, select the required queue.
6. Select **Create**. The user appears in the user list with a **Pending activation** status.

## Verify the account

1. Search the user list for the new agent's email address.
2. Open the account and confirm the role and queue assignment.
3. Confirm that the agent receives the activation invitation through the organization's approved channel.

:::tip
Assign only the roles and queues that the agent needs to perform their work.
:::
